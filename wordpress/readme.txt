=== Living Culture ===
Requires at least: 5.0
Requires PHP: 7.4
Stable tag: 1.0.0
License: GPLv2 or later

The Living Culture young adult Bible study site inside your WordPress website.

== Description ==

Adds the Living Culture site (notice board, calendar with the Thursday 19:00 gathering,
breaks/cancellations, prayer requests & questions, and the Bible reader) at
yoursite.com/livingculture/ – as its own pages, so your WordPress theme is not affected.

All content (notices, events, requests) lives in the Living Culture Supabase database,
and leaders log in at yoursite.com/livingculture/admin.html with their Living Culture
leader login (not a WordPress account).

== Installation ==

1. WordPress dashboard → Plugins → Add New → Upload Plugin → choose living-culture-wordpress.zip → Install Now → Activate.
2. Visit yoursite.com/livingculture/
3. Optional: change the address under Settings → Living Culture.

== Updating ==

Upload the newest living-culture-wordpress.zip the same way; WordPress offers to replace the current version.
